SYSTEM ALBUM - ANIMATED LOGO

Files:
- system-album-animated.svg: the animated logo with embedded CSS.
- preview.html: a self-contained preview. Open in a browser to watch and refresh to replay.

To use the SVG in a website, put the SVG alongside your HTML file and add:
<img src="system-album-animated.svg" alt="System Album">

The animation starts when the image loads. A full-page loading screen needs additional website code; this ZIP contains the logo and preview, not the complete website. Browsers or devices with reduced-motion preferences may show less animation.
